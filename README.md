# Multi-AI House Zero

Mở trang chính để chuyển việc giữa năm AI bằng tay, hoặc chọn **Chạy tự động với hai AI** để Gemma viết bản nháp và GPT-OSS kiểm tra bản nháp rồi trả sản phẩm cuối.

Chế độ tự động gọi hai mô hình miễn phí qua OpenRouter. Cần [khóa OpenRouter](https://openrouter.ai/settings/keys). Khóa ở trong tab cho đến khi tải lại hoặc đóng trang, còn bản nháp và bản cuối gần nhất được lưu trên trình duyệt. Nếu bước kiểm tra lỗi, nhập lại khóa nếu cần và bấm **Chạy lại bước kiểm tra**. Giữ trang mở trong khi xử lý.

Trang triển khai bằng GitHub Pages sau khi GitHub Actions chạy kiểm thử trình duyệt.
